How to read this map

Each box is a function. Endpoints sit on the left and fan out to whatever they call. Every value keeps one colour everywhere it travels.

Reading
Hover a variable to trace it across rows, code and arrows. Hover a row to light up the arrow it sends.
Click a variable to number its path: where it comes from and where it goes. The ? on a box asks where a parameter comes from, why the box can fail, or which routes reach it.
Click a row to jump to that call site in the code. Click an underlined call in the code to fly to its box.
Solid arrows carry arguments in. Dashed arrows carry the typed return value back.
